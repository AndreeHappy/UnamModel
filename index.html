Guía Rápida de Edición (config.js)

Todo el edificio, lugares, letreros y red de zonas caminables están definidos en config.js.

1. Agregar un nuevo lugar: 
// 1) Añade un waypoint en `nodosCaminables`:
wp_bienestar: [2.0, 1.65, 2.2],

// 2) Conéctalo en `conexiones` (estado: 'libre' o 'muro'):
{ desde: 'wp_pasillo_oeste', hacia: 'wp_bienestar', estado: 'libre' },

// 3) Registra el destino en `lugares`:
bienestar: {
  id: 'bienestar',
  nombre: 'Bienestar',
  titulo: 'Oficina de Bienestar Universitario',
  tramites: 'Atención estudiantil, comedor y servicio social.',
  horario: 'Lunes a Viernes: 08:00 - 15:45',
  posicion: [2.0, 1.65, 2.2],
  orientacionLlegada: [2.0, 2.1, 5.5],
  nodoRed: 'wp_bienestar',
  letrero: { texto: 'BIENESTAR', pos: [2.0, 2.85, 5.45], rotY: Math.PI, ancho: 3.2 },
}
2. Mover o agregar un bloque o muro (siempre a la misma altura): 
// En `bloquesPlano` dentro de config.js usa límites exactos [xMin, xMax, zMin, zMax]:
{ nombre: 'Nuevo Bloque', xMin: 33.0, xMax: 38.0, zMin: 26.5, zMax: 32.5 }
3. Activar un nuevo piso: 
// En `pisos` dentro de config.js cambia `activo: true`:
{ id: 2, nombre: 'Piso 2', activo: true }
