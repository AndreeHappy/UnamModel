# UnamModel

Recorrido virtual 3D en primera persona de los 4 pisos de la Sede Administrativa de la Universidad Nacional de Moquegua (UNAM), optimizado a 120 FPS con batching estático de líneas y geometrías en Three.js.

## Ejecución local

```bash
npm install
npm start
```

Abrir `http://localhost:5173`.
